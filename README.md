# 🐱 SAVE MOMO — 프로토타입

한 번에 선을 그어 고양이 **모모**를 지키는 물리 퍼즐 게임입니다.
선을 다 그리면 물리 시뮬레이션이 시작되고, 10초 동안 드론·빗물·물풍선 같은 위협을 막아내면 성공입니다.

## 플레이 방법
1. 화면에 **한 번에** 선을 그립니다. 손을 떼면 선이 물리 법칙대로 떨어집니다.
2. **10초** 동안 모모의 체력이 남아 있고 화면 밖으로 떨어지지 않으면 성공입니다.
3. 잉크를 적게 쓸수록 점수가 높습니다. 잉크 사용량이 22% 이하면 ⭐3개, 40% 이하면 ⭐2개입니다.

## 맵 구성
레벨마다 맵이 절차적으로 생성됩니다. 같은 레벨은 누구에게나 같은 맵입니다.

| 구분 | 종류 |
|---|---|
| 모모가 앉는 지형 (11종) | 공중 받침대 · 언덕 들판 · 벽 선반 · 기둥 꼭대기 · 골짜기 · 절벽 · 동굴 · V자 그릇 · 시소(움직임) · 매달린 발판(움직임) · 계단 |
| 장애물 | 나무 판자 · 상자 · 바위 |
| 위협 | 드론 떼 · 빗물 · 물풍선 · 바람 · 물총 오리 · 불독 |
| 도우미 | 고정 핀: 선이 핀 근처를 지나가면 그 자리에 고정됩니다 |
| 배경 | 낮 · 노을 · 밤 · 숲 |

- 새 요소는 2~7레벨에서 하나씩 처음 등장합니다. 8레벨부터는 위협 1~3종이 무작위로 섞입니다.
- **오늘의 챌린지**는 날짜로 정해지는 맵이라 모두가 같은 문제를 풉니다. 결과를 복사해 공유할 수 있습니다.

## 모모의 표정
잠든 모습(선 그리기 중) · 기본 · 놀람(위협이 가까울 때) · 아픔(맞았을 때) · 걱정(체력 40 미만) · 하트(성공)

## 실행
빌드 과정이 없는 정적 페이지입니다. `index.html`과 `assets/` 폴더를 함께 GitHub Pages로 배포하면 됩니다.
물리 엔진으로 [Matter.js](https://brm.io/matter-js/) 0.19.0을 CDN에서 불러옵니다.

## 상태
초기 프로토타입입니다. 핵심 재미("잉크를 아끼며 막아내기")를 검증하는 단계입니다.
