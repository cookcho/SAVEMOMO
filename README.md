# 🐱 SAVE MOMO — 프로토타입

한 번에 선을 그어 고양이 **모모**를 지키는 물리 퍼즐 게임입니다.
선을 다 그리면 물리 시뮬레이션이 시작되고, 7초 동안 드론·빗물·물풍선 같은 위협을 막아내면 성공입니다.

## 이야기
햇살 좋은 오후, 낮잠을 사랑하는 고양이 모모. 그런데 오늘은 목욕하는 날! 집사는 물 드론·물총 오리·물풍선을 꺼냈고, 옆집 불독까지 놀자고 달려옵니다. 물이라면 질색인 모모를 펜 한 자루로 지켜 주세요.

처음 실행하면 이야기 4장면과 1레벨 튜토리얼(점선 따라 그리기)이 나옵니다. 아래쪽 **📖 이야기** 버튼으로 다시 볼 수 있습니다.

## 플레이 방법
1. 화면에 **한 번에** 선을 그립니다. 손을 떼면 선이 물리 법칙대로 떨어집니다.
2. **7초** 동안 모모의 체력이 남아 있고 화면 밖으로 떨어지지 않으면 성공입니다.
3. 잉크를 적게 쓸수록 점수가 높습니다. 잉크 사용량이 22% 이하면 ⭐3개, 40% 이하면 ⭐2개입니다.

## 맵 구성
레벨마다 맵이 절차적으로 생성됩니다. 같은 레벨은 누구에게나 같은 맵입니다.

| 구분 | 종류 |
|---|---|
| 모모가 있는 지형 (14종) | 공중 받침대 · 언덕 들판 · 벽 선반 · 기둥 꼭대기 · 골짜기 · 절벽 · 동굴 · V자 그릇 · 시소(움직임) · 매달린 발판(움직임) · 계단 · **땅굴 · 우물 · 절벽 굴(파낸 지형)** |
| 장애물 | 나무 판자 · 상자 · 바위 |
| 위협 | 드론 떼 · 헤비 드론(27) · 빗물 · 물풍선 · 바람 · 물총 오리 · 강아지 · 큰 개(33) |
| 도우미 | 고정 핀: 선이 핀 근처를 지나가면 그 자리에 고정됩니다 |
| 배경 | 낮 · 노을 · 밤 · 숲 |

- 새 요소는 2~7레벨에서 하나씩 처음 등장합니다. 8레벨부터는 위협 1~3종이 무작위로 섞입니다.
- **오늘의 챌린지**는 날짜로 정해지는 맵이라 모두가 같은 문제를 풉니다. 결과를 복사해 공유할 수 있습니다.

## 난이도
레벨마다 **난이도 지수 D**를 계산하고, 모든 변수가 D에 맞춰 함께 움직입니다.

- **큰 흐름:** D = 0.12 + 0.88 × (1 − e^(−레벨/30)) + 0.004 × (레벨 − 60, 60 이후). 60레벨까지 빠르게, 이후에도 완만하게 계속 오릅니다.
- **챕터 안 흐름:** 10레벨 단위로 오르내립니다(−0.06 … +0.09). 10번째는 🔥 보스(+0.16), 다음 챕터 첫 판은 숨 고르기입니다.

| 변수 | D에 따른 변화 |
|---|---|
| 잉크 길이 | 620 − 380·D (최소 210), 파낸 지형은 ×0.85 |
| 위협 예산 | 8 + 100·D^1.15 (보스 ×1.1, 새 요소 소개 ×0.85) |
| 위협 상한 | D 0.68 초과분 × 2.6만큼 드론 수·사격 속도 상한 확대 |
| 적 물리력 | 0.75 + 0.85·D (보스 +0.1): 선을 튕기는 충격·돌진 추력 배율 |
| 적 속도 | 2.0 + 1.9·D |
| 지형 단계 | 쉬움(받침대·들판·땅굴) → 보통(절벽·선반·골짜기·우물·동굴) → 어려움(계단·기둥·그릇·절벽 굴) → 매우 어려움(매달린 발판·시소). D×3.2 근처 단계가 자주 나옴 |
| 위협 종류 | 1종 → 2종 → 2~3종 → 3~4종 |
| 퍼즐 규칙 | 31·34·37레벨 소개, 38레벨부터 무작위, 보스는 1개 이상 |
| 고정 핀 | 확률 0.75 − 0.35·D (31레벨부터 최소 1개 보장) |

화면 상단 칩에 `난이도 ▮▮▮▯▯ 6`처럼 1~10 단계로 표시됩니다.

## 앱으로 설치하기
- **안드로이드(크롬):** 게임 아래쪽 **📲 설치** 버튼을 누르거나, 크롬 메뉴 → "앱 설치"
- **아이폰(사파리):** 공유 버튼 → "홈 화면에 추가"
- 한 번 열고 나면 인터넷 없이도 실행됩니다(서비스 워커 캐시).
- 새 버전을 배포할 때 이미지·`lib/` 파일을 바꿨다면 `sw.js`의 `CACHE` 이름(예: `savemomo-v2`)을 올려야 설치된 앱에도 반영됩니다.

## 실행
빌드 과정이 없는 정적 페이지입니다. `index.html`과 `assets/` 폴더를 함께 GitHub Pages로 배포하면 됩니다.
물리 엔진으로 [Matter.js](https://brm.io/matter-js/) 0.19.0(MIT 라이선스)을 `lib/`에 포함해 오프라인에서도 동작합니다.

## 별 · 상점 · 챕터 문

- 별은 레벨별 최고 기록과 오늘의 도전 기록에서 모입니다. 기준은 잉크 양(px): 지형마다 '꼭 필요한 최소 잉크'(par: 땅굴·우물 95, 계단 150, 그릇 170, 들판·절벽 190, 기둥·매달린 발판·시소 205)를 두고 ★3 = par 이하, ★2 = par×1.5 이하, 성공 ★1. 잉크를 넉넉히 주는 레벨은 예전 기준(22%·40%)이 더 너그러우면 그쪽을 씀. 잉크 막대의 ★ 표시가 이 기준선
- 챕터 문: 챕터 N(11레벨부터 10레벨마다)에 들어가려면 지금까지 모은 별이 (N−1)×12개 이상이어야 합니다. 상점에서 별을 써도 모은 별은 줄지 않습니다. 업데이트 전에 이미 간 레벨까지는 문이 없습니다. (`GATE_PER_CH`)
- 상점(쓸 수 있는 별 = 모은 별 − 쓴 별)
  - 아이템(한 판에 하나씩 씀): 긴 펜(잉크 +25%) ★3, 튼튼 펜(선이 밀리는 힘 절반) ★3, 모래시계(버틸 시간 −1초) ★4. 처음에 하나씩 줍니다. 별 계산은 기본 잉크 기준이라 긴 펜을 써도 별이 쉬워지지 않습니다.
  - 펜 꾸미기: 빨강·초록·보라 ★5, 분필 ★8, 무지개 ★15, 황금 ★20
  - 모모 꾸미기: 꽃 핀 ★6, 리본·야구 모자 ★8, 선글라스·물안경 ★10, 실크해트 ★12, 왕관 ★15. `assets/sprites/acc_<이름>.png`가 있으면 그 그림, 없으면 이모지로 표시

## 소리 (audio.js)

음원 파일 없이 Web Audio로 코드에서 직접 만듭니다. 첫 터치 때 켜지고(브라우저 정책), 화면을 벗어나면 멈춥니다.

- 배경음악: 시작 화면 + 챕터 7곡. 챕터마다 조성·빠르기·악기가 다름(거실 마림바, 마당 피리, 지붕 노을 종소리·패드, 공원 피리, 바닷가 우쿨렐레·스틸드럼, 비 오는 골목 일렉 피아노+빗소리, 목욕탕 뽀글 소리). 선을 긋는 동안은 잔잔하게, 버티는 7초 동안은 드럼이 들어옴
- 주변 소리: 드론 웅웅(수에 따라 커짐), 비구름이 있으면 빗소리
- 효과음: 연필 사각사각, 핀, 선 떨어짐, 충돌, 물풍선, 오리 꽥·물총, 개 짖음, 모모 야옹, 마지막 3초 째깍, 성공·실패, 별, 상점 구매 등
- 설정(시작 화면 톱니바퀴)에서 배경음악·효과음을 따로 끌 수 있음
